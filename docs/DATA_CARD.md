# Data Card: UCI SECOM

## Purpose

Benchmark rare-failure screening on high-dimensional manufacturing process data.

## Data

- Source: UCI Machine Learning Repository, DOI `10.24432/C54305`.
- License: CC BY 4.0.
- Contents: 1,567 samples, 590 anonymized numeric process measurements, timestamps, and pass/fail labels.

## Use and limitations

SemiYield downloads SECOM at runtime and does not redistribute it. The dataset has 104 failure samples and no disclosed feature, fab, product, process-node, or label-generation semantics. Use it for reproducible method evaluation, not physical process-step identification or production-performance claims.
